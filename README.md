# IIT Madras MLP Project: Predictive Regression Pipeline

This repository contains the end-to-end machine learning pipeline developed for the Machine Learning Practice (MLP) course at IIT Madras. 

## Project Overview
The objective of this project is to build a robust regression model for a private Kaggle competition dataset. The pipeline handles data preprocessing, feature engineering, and hyperparameter tuning to optimize predictive accuracy.

## Key Achievements
* **Algorithm:** LightGBM Regressor
* **Validation Strategy:** K-Fold Cross-Validation
* **Performance:** Achieved an Out-Of-Fold RMSE score of **0.19281**

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, LightGBM, Matplotlib, Seaborn

## Repository Structure
* `train.csv` - The primary training dataset (private competition data).
* `main-pipeline.ipynb` - The Jupyter Notebook containing the complete exploratory data analysis (EDA), model training, and evaluation.
